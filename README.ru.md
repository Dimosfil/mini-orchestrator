# Mini Orchestrator

[English](README.md) · **Русский** · [Подробное руководство](docs/README.extended.ru.md)

Mini Orchestrator — локальная наблюдаемая среда для создания и запуска
AI-воркфлоу с обязательным подтверждением пользователя. Пользователь описывает
задачу, проверяет предложенный план, явно подтверждает его и наблюдает, как
выбранная цепочка агентов выполняет работу по этапам.

Пример задачи:

```text
оркестратор план Сделай калькулятор
```

## Основные функции

- предварительный просмотр плана до запуска;
- запуск сохранённых цепочек, например `планировщик -> исполнитель -> ревьюер`;
- визуальное создание и сохранение карточек агентов и связей между ними;
- два адаптера исполнения: Dispatcher и Symphony;
- просмотр этапов, логов, времени выполнения, данных воркеров и сырых результатов;
- хранение состояния проекта в SQLite;
- ручная приёмка результата через Human Review.

Цепочка из трёх агентов — только стартовый пример, а не жёстко заданная схема.
Сохранённый пресет может содержать любое допустимое количество агентов в нужном
порядке.

## Быстрый старт

Требования: Python 3.10+ и необходимые для запуска записи сервисов в GI
config-service.

```powershell
python -m venv .venv
. .venv\Scripts\Activate.ps1
python -m pip install -e .
python -m mini_orchestrator --ui
```

После запуска откройте интерфейс, введите задачу, запросите план, проверьте его,
подтвердите и запустите workflow.

## Текущее состояние

Сейчас Mini Orchestrator — экспериментальная лаборатория оркестрации, а не
готовая промышленная платформа. Основной интерфейс — панель оркестратора.
Dispatcher запускается напрямую, а Symphony подключается через проверяемый
контракт. Визуальный конструктор сохраняет схемы и пресеты, но их выполнение
всегда начинается из главной панели после явного подтверждения.

Архитектура, режимы исполнения, хранение данных, интеграции, API, настройки и
команды проверки описаны в
[подробном руководстве на русском](docs/README.extended.ru.md).
